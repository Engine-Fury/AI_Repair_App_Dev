
# Fury AI

## Overview

Fury AI is an advanced platform for AI-powered fleet repair bill analysis and automation. Built for speed, accuracy, and seamless integration, Fury AI helps fleets and service providers process, analyze, and optimize repair bills using state-of-the-art machine learning and automation tools.

## Features

- Automated fleet repair bill processing
- AI-driven analysis and insights
- Modern, responsive dashboard
- Secure and scalable architecture

## Technologies Used

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## Getting Started

To run Fury AI locally:

```sh
# Clone the repository
git clone <YOUR_GIT_URL>

# Navigate to the project directory
cd <YOUR_PROJECT_NAME>

# Install dependencies
npm install

# Start the development server
npm run dev
```
